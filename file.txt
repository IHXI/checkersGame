Create an 8*8 board.
Set the first player as black.
Repeat while there is no winner and the board is not empty:
Ask the current player to make a move.
Check if the space is empty.
If empty and it's a legal move, place the player’s piece there.
Check if both players have pieces.
If no, announce the winner.
If yes, switch turns between white and black.
If there are no moves left and no one won, announce a tie.
